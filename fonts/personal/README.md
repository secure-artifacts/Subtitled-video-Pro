Personal fonts folder
=====================

Put local personal-use font files here, such as `.ttf` or `.otf`.

Fonts in this folder are loaded by the app for local preview/rendering only.
They are registered as personal/non-commercial fonts, are not added to the
open font manifest, and should not be redistributed, uploaded to GitHub, or
bundled into release packages unless you have separate redistribution rights.

For Bernoru/Bernoru Sans, use this folder only with your own personal license
or sample/trial file from the designer's official source.
